# aimonetiz / radar — пошаговая инструкция

Публичный сайт, который показывает залетающие YouTube Shorts по нише и стране.
Используется **YouTube Data API v3** (бесплатно, до 10 000 запросов в день).

---

## Что тебе понадобится

1. Аккаунт Google (любой gmail)
2. Аккаунт GitHub (бесплатный, регистрация 1 минута)
3. Аккаунт Vercel (бесплатный, можно через GitHub)
4. ~20 минут времени

**Платить ничего не нужно** — YouTube API даёт большой бесплатный лимит, Vercel хостит бесплатно.

---

## ШАГ 1. Получить YouTube API ключ (5 минут)

1. Открой `https://console.cloud.google.com/`
2. Войди под своим Google-аккаунтом
3. Сверху слева, рядом с логотипом, нажми на список проектов → **"New Project"**
4. Назови проект `aimonetiz-radar` → нажми **Create**
5. После создания убедись, что новый проект выбран в шапке
6. В поиске сверху введи **"YouTube Data API v3"** → открой → нажми **Enable**
7. Слева в меню: **APIs & Services → Credentials**
8. Нажми **+ Create Credentials → API key**
9. Скопируй ключ (выглядит как `AIzaSy...`) и сохрани в заметках — он нужен на шаге 4
10. (Опционально, но желательно) Нажми на ключ → **Edit API key** → в разделе **API restrictions** выбери **Restrict key** → поставь галочку только на **YouTube Data API v3** → Save

✅ **Готово.** У тебя есть YouTube API ключ.

---

## ШАГ 2. Загрузить код на GitHub (5 минут)

1. Открой `https://github.com/` и зарегистрируйся (если ещё нет аккаунта)
2. Сверху справа нажми **"+" → New repository**
3. Имя репозитория: `aimonetiz-radar`
4. Выбери **Public** (бесплатный план не поддерживает приватные с Vercel-фичами)
5. Поставь галочку **Add a README file**
6. Нажми **Create repository**

Теперь нужно загрузить файлы проекта:

7. В созданном репозитории нажми **Add file → Upload files**
8. Распакуй архив `aimonetiz-radar.zip` (присланный мной) на компьютере
9. **Перетащи ВСЕ файлы и папки** из распакованной папки (api/, src/, package.json, index.html и т.д.) в окно GitHub
10. Прокрути вниз → нажми **Commit changes**

✅ **Готово.** Код на GitHub.

---

## ШАГ 3. Задеплоить на Vercel (5 минут)

1. Открой `https://vercel.com/`
2. Нажми **Sign Up → Continue with GitHub** → разреши доступ
3. После входа нажми **Add New... → Project**
4. Найди в списке свой репозиторий `aimonetiz-radar` → нажми **Import**
5. На странице настроек **ничего не меняй** — Vercel сам определит, что это Vite-проект
6. Нажми **Deploy**
7. Подожди 1-2 минуты, пока идёт сборка

⚠️ **Сайт задеплоится, но ПОКА НЕ БУДЕТ РАБОТАТЬ** — он не знает твоего YouTube ключа. Идём дальше.

---

## ШАГ 4. Подключить YouTube ключ (2 минуты)

1. В Vercel зайди в свой проект → **Settings → Environment Variables**
2. Заполни поля:
   - **Key:** `YOUTUBE_API_KEY`
   - **Value:** вставь YouTube ключ из Шага 1 (тот, что `AIzaSy...`)
   - **Environments:** оставь все галочки (Production, Preview, Development)
3. Нажми **Save**

Теперь нужно **передеплоить**, чтобы ключ подхватился:

4. Слева в меню перейди в **Deployments**
5. На последнем деплое нажми три точки **"⋯" → Redeploy → Redeploy**

Подожди ~1 минуту. Готово!

---

## ШАГ 5. Открой свой сайт 🎉

Зайди в Vercel → твой проект → сверху увидишь URL вида:

```
https://aimonetiz-radar.vercel.app
```

Открой — выбери нишу, страну, период → нажми **"Найти залётыши"** → должны появиться карточки виральных Shorts.

## Опционально: свой домен

1. Купи домен (например, на `Namecheap` или `Reg.ru`) — `aimonetiz.com` стоит ~$10/год
2. В Vercel → Project Settings → **Domains** → добавь свой домен
3. Vercel покажет, какие DNS-записи прописать у регистратора
4. Через ~10 минут сайт будет работать по твоему домену

## Если что-то не работает

**Сайт пустой / ничего не происходит:**
- Открой DevTools (F12) → Console → посмотри ошибку
- Чаще всего проблема в YouTube ключе (не задан / не подхватился после redeploy)

**Ошибка "quota exceeded":**
- Лимит 10 000 запросов в день исчерпан (это редко, нужно очень много трафика)
- Подожди до завтра или создай второй ключ

**Ошибка "API key not valid":**
- Ключ задан с ошибкой — проверь, что нет лишних пробелов
- Проверь, что YouTube Data API v3 включён в Google Cloud Console

**Хочешь поменять список ниш:**
- Открой файл `api/search.js` → найди `NICHE_QUERIES` → отредактируй
- Открой `src/App.jsx` → найди `NICHES` → отредактируй (имена должны совпадать)
- Commit изменения на GitHub → Vercel задеплоит автоматически
